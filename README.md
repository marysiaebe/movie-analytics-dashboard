# Interactive Movie Analytics Dashboard

## Overview

This project is an interactive dashboard developed in R using Shiny for exploring movie and TV series data.

The application enables users to analyze production trends, IMDb ratings, voting statistics and geographical distribution of TV series through interactive visualizations and maps.

---

## Features

- Interactive world map of TV series production
- IMDb votes vs IMDb score visualization
- TV series seasons analysis
- Movie category trends over time
- Interactive filters for years and categories
- Responsive Shiny interface

---
